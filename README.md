# The Agent Commerce Investment Stack

Interactive HTML slide deck for Ken Huang’s seven-layer framework on where value, risk, and opportunity concentrate as autonomous agents transact on behalf of consumers.

**Live site:** https://kenhuangus.github.io/agent-commerce-investment-stack/

**Source talk:** [Google Slides](https://docs.google.com/presentation/d/1K2tfgJ_khJ8dkfJFsLltPVKtNcLlhrZM978gEBfTTZc/edit)

## Local preview

Open `index.html` in a browser, or:

```bash
python -m http.server 8080
# http://localhost:8080
```

## Controls

| Key | Action |
|-----|--------|
| → / Space / PageDown | Next slide |
| ← / PageUp | Previous slide |
| F | Fullscreen |
| Click progress dots | Jump to slide |
